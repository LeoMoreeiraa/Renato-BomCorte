# Barbearia Bom Corte - Estilo e Tradição

Este é o repositório do site institucional da **Barbearia Bom Corte**. O projeto foi desenvolvido para apresentar os serviços, a tradição e facilitar o agendamento de clientes.

⚠️ **Aviso:** Este projeto **não está totalmente pronto**. Algumas funcionalidades e detalhes visuais ainda estão em fase de desenvolvimento e ajustes.

---

## 🚀 Funcionalidades e Destaques

Com base na estrutura atual da página, o site oferece:

* **Design Profissional:** Interface focada na experiência do usuário, com estética clássica e limpa.
* **Integração com WhatsApp:** Botões de agendamento direto para facilitar a conversão de clientes.
* **Localização no Mapa:** Endereço detalhado (Vila Constança, SP) para que os clientes encontrem o local facilmente.
* **Catálogo de Serviços:** Seções dedicadas para explicar os diferenciais da barbearia (Cortes modernos, profissionais qualificados e horários flexíveis).
* **Navegação Completa:** Menu estruturado em Início, Serviços, Mostruário e Contato.

## 🔗 Conectividade e Redes Sociais

O site conta com links estratégicos para facilitar o contato:
* **WhatsApp:** Botão flutuante e links no corpo da página.
* **Redes Sociais:** Ícones e links para conexão com o público.
* **Contato Direto:** Email e telefone disponíveis no rodapé.

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **Hospedagem:** GitHub Pages
