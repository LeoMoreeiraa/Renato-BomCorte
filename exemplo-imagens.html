🎯 Guia de Uso das Imagens Locais - Barbearia Bom Corte

1. Logo da Barbearia

Substitua o placeholder do logo por uma imagem real:

HTML:
<img src="images/logo/logo.png" alt="Bom Corte Barbearia">
CSS (se quiser como background):
.logo {
  background-image: url('images/logo/logo.png');
  background-size: contain;
  background-repeat: no-repeat;
}

2. Galeria de Cortes

Substitua as imagens do Unsplash por fotos reais dos seus trabalhos:

No mostruario.html, substitua:
ANTES: style="background-image: url('https://images.unsplash.com/photo-1621605815971-fbc98d665033?w=600');"

DEPOIS: style="background-image: url('images/gallery/corte-01.jpg');"

3. Imagem de Fundo da Homepage

Para adicionar uma foto da barbearia como fundo:

CSS:
.hero {
  background-image: url('images/background/hero-background.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
}

4. Estrutura de Arquivos Criada

📁 images/
├── 📄 README.md (documentação)
├── 📄 guia-de-uso.css (exemplos CSS)
├── 📁 logo/ (logo da barbearia)
├── 📁 gallery/ (fotos dos cortes)
├── 📁 background/ (imagens de fundo)
├── 📁 services/ (imagens dos serviços)
└── 📁 contact/ (imagens do contato)

5. Próximos Passos

  1. 📸 Tire fotos dos seus trabalhos e coloque na pasta gallery/
  2. 🏪 Fotografe a barbearia (externa/interna) para background/
  3. 🎨 Crie ou obtenha o logo da barbearia para logo/
  4. 👥 Foto da equipe para a página de contato
  5. 🔧 Substitua as URLs nos arquivos HTML pelos caminhos locais

6. Dicas Importantes

  • ✅ Use JPG para fotos (menor tamanho)
  • ✅ Use PNG para logos (suporte à transparência)
  • ✅ Otimize as imagens (máximo 500KB cada)
  • ✅ Use nomes descritivos sem espaços
  • ✅ Resolução recomendada para galeria: 800x600px
  • ✅ Resolução recomendada para backgrounds: 1920x1080px
