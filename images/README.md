# Estrutura de Imagens - Barbearia Bom Corte

Esta pasta contém todas as imagens organizadas por categoria para facilitar a manutenção do site.

## Estrutura de Pastas:

### `/logo/`
- Logo da barbearia (formatos: PNG, SVG recomendados)
- Exemplo: `logo.png`, `logo-white.png`, `logo.svg`

### `/gallery/`
- Fotos dos cortes realizados na barbearia
- Fotos do mostruário de trabalhos
- Formato recomendado: JPG ou WebP
- Resolução recomendada: 800x600px ou superior

### `/background/`
- Imagens de fundo para a página inicial
- Fotos da barbearia (externa/interna)
- Formato recomendado: JPG
- Resolução recomendada: 1920x1080px ou superior

### `/contact/`
- Fotos para a página de contato
- Imagens da localização, fachada da barbearia
- Fotos dos profissionais

### `/services/`
- Imagens dos serviços oferecidos
- Fotos de equipamentos, produtos
- Imagens ilustrativas dos tipos de corte

## Dicas de Otimização:
- Use formatos WebP quando possível para melhor performance
- Mantenha arquivos com tamanho otimizado (máximo 500KB por imagem)
- Use nomes descritivos para os arquivos
- Evite espaços nos nomes dos arquivos (use hífen ou underscore)

## Exemplos de Nomenclatura:
- `logo-principal.png`
- `corte-degradee-01.jpg`
- `barbearia-fachada.jpg`
- `servico-barba.jpg`
